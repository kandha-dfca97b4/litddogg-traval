现在这份清单保存在当前设备。配置 Supabase 后，就能创建共享空间，让两个人在不同手机上双向实时同步。

  1. 创建免费的 Supabase 项目。
  2. 执行仓库里的 supabase/schema.sql。
  3. 把项目 URL 和 anon public key 填进 config.js。

只使用 anon public key，绝不要把 service_role 密钥放进网页或公开仓库。
