# 出行带什么 🧳

两个人的小行李，一张清单就够啦 ♡

这是一个 mobile-first 的双人旅行打包清单。目标是让两个人通过同一个邀请链接共同编辑，并在设备之间实时同步。

## 当前开发约定

- 纯静态前端，托管目标为 GitHub Pages；不依赖 Lovable、Vercel 或 Cloudflare。
- 未配置 Supabase 时仅提供本机 localStorage 体验，不会假装实现跨设备同步。
- 配置 Supabase 后，通过随机邀请凭据和受控 RPC 读写共享数据；实时频道只发送刷新通知。
- 绝不把 Supabase `service_role` 密钥放进前端或公开仓库。

## 功能目标

- 目的地、出行日期、两位成员名称。
- 分类清单、每人独立勾选、每人备注、进度统计。
- 搜索、新增/编辑/删除物品、自定义分类、折叠分类。
- 一键重置勾选状态，保留清单和备注。
- 分享邀请链接、双向实时同步、导出清单图片。

## 本地体验

直接用浏览器打开 `index.html` 即可体验本地清单。共享同步需要先配置 Supabase，详见 `supabase/schema.sql` 和后续配置说明。
